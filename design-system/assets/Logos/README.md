# Logos

- `applicable-mark.svg` — the tile alone (48×48): tangerine `#F26A3D` (brand), highlighter `#FFE38A` (highlight), check `#1F1B16` (ink). Favicon, `st.logo(icon_image=…)`, avatars. Works on light and dark grounds.
- `applicable-lockup.svg` — tile + wordmark, ink `#1F1B16` with ".ai" in `#B63F16` (brand-ink). Light grounds only (canvas, surface).
- `applicable-lockup-on-dark.svg` — same, wordmark `#F5EFE6` with ".ai" in `#FF9C73`. Dark grounds only.

Wordmark is Bricolage Grotesque ExtraBold, outlined. Minimum height 24px; clear space = half the tile. Never recolour the tile or separate the check from the highlighter.
