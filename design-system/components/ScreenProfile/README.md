# ScreenProfile

*My profile*: what the AI understood, always with a source. Tabs — **From your CV** (summary numbers, items to confirm, skills with their quote, experience timeline) · **Preferences** · **Facts you told us** (every `YOU` fact, dated, editable — the memory of answered questions) · **CV versions**.

**Streamlit:** `st.tabs`; skill chips as `st.pills` whose selection renders the EvidenceQuote; confirmations as `st.pills` per item; timeline via `st.html()`.
